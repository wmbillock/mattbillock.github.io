Agent systems

Multi-agent orchestration, mostly organized the way a drum corps or a band is: clear roles, a chain of command, and a score at the end.

  • DrumSwarmInternational

    An agent orchestration swarm built on a drum and bugle corps metaphor. Corps of AI agents work through seasons of shows, scored performances and reputation-driven drafting, with a design room, rehearsal modes and judging.

    FastAPI · SQLAlchemy · Alembic · React 19 · TypeScript · Vite

    PythonTypeScript

  • ensemble

    A hierarchical multi-agent system that builds software test-first. More than 25 agent roles, from an executive director down to test writers, with code-writing permissions enforced at the tool level, a self-improvement loop and a live monitoring UI.

    Anthropic SDK · FastAPI · WebSockets · React 19 · Redux Toolkit · Tailwind

    PythonJavaScript
