# Willow Billock

Source for my personal site: a billboard for my public GitHub work and a short intro page.

- `index.html`: selected public projects
- `about.html`: about me
- `assets/aw.css`: the Arcade Willow design system (rev 4)
- `assets/site.css`: page layout on top of it

Plain static HTML and CSS, no build step. `.nojekyll` tells GitHub Pages to serve the files as they are.
